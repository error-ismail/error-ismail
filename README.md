# 🧪 Interactive Periodic Table

### ⚛️ A chemistry learning application built as an interactive desktop experience.

</div>

A feature-rich **Java Swing** application containing information for **all 118 chemical elements**, with interactive tools for learning and experimentation.

<div align="center">

| 🔬 Explore | ⚗️ Experiment | 📊 Visualize |
|:---:|:---:|:---:|
| Element Search | Compound Builder | Trends Graph |
| Bohr Model | Atom Builder | Match Game |
| Grid / Spiral Layout | Flame Test | PNG Export |
| Element Details | Category Tools | Dark Mode |

</div>

**🧰 Built with**

`Java` `Swing` `AWT` `OOP` `Collections` `Preferences` `ImageIO`

```text
                     ⚛️ PERIODIC TABLE
                            │
            ┌───────────────┼───────────────┐
            ▼               ▼               ▼
        🔬 TABLE         ⚗️ LAB          ⚙️ SETTINGS
            │               │               │
       ┌────┼────┐     ┌────┼────┬────┐      ├─ 🌙 Dark Mode
       ▼    ▼    ▼     ▼    ▼    ▼    ▼      └─ 🌀 Spiral
      Grid Spiral Search Atom Flame Trends Match
                     Builder Test  Graph  Game
```

**🧪 Validation**

`ElementDataTest.java` validates the element dataset, atomic-number coverage, masses, shell calculations, valence references, GCD logic and selected configurations.
