# 🧪 Interactive Periodic Table

### *A chemistry application disguised as a desktop experiment.*

A Java Swing application containing information for **all 118 chemical elements**, with interactive learning tools rather than a static table.

**Explore**

`Element Search` · `Bohr Model` · `Compound Builder`  
`Atom Builder` · `Flame Test` · `Trends Graph`  
`Match Game` · `Dark Mode` · `PNG Export`

**Built with**

`Java` `Swing` `AWT` `OOP` `Collections` `Preferences` `ImageIO`

### Internal Architecture

```text
                    ┌─────────────────────┐
                    │  PERIODIC TABLE     │
                    └──────────┬──────────┘
                               │
            ┌──────────────────┼──────────────────┐
            │                  │                  │
            ▼                  ▼                  ▼
         TABLE              LAB TOOLS          SETTINGS
            │                  │                  │
       ┌────┼────┐        ┌────┼────┬────┐      ├─ Dark Mode
       │    │    │        │    │    │    │      └─ Spiral Layout
      Grid Spiral Search  Atom Flame Trends Match
                         Builder Test  Graph  Game
```

**Validation:** `ElementDataTest.java` checks the element dataset, atomic-number coverage, masses, shell calculations, valence references, GCD logic and selected known configurations.
